# Movie Code Bot

Telegram-бот: пользователь присылает 3-значный код — бот присылает название
фильма и постер (фото). Интерфейс для пользователей — на узбекском языке,
команды и ответы для разработчика — на русском.

## Структура проекта

```
movie-code-bot/
├── bot.py              # точка входа
├── config.py            # переменные окружения
├── database.py           # работа с SQLite (aiosqlite)
├── keyboards.py           # инлайн-клавиатура подписки
├── handlers/
│   ├── user.py           # /start, проверка подписки, поиск по коду
│   └── admin.py           # команды разработчика
├── requirements.txt
├── Procfile              # для Railway
└── .env.example
```

## Логика бота

- Если в базе **нет ни одного кода** (разработчик ещё ничего не добавил),
  на `/start` бот отвечает фиксированным текстом про отсутствие рекламодателей
  (с контактом `@lixuauto`) — без кнопок.
- Если коды есть, но пользователь **не подписан** на все обязательные каналы —
  бот показывает список каналов инлайн-кнопками + кнопку «✅ Tekshirish».
- Если пользователь подписан — можно присылать 3-значный код, бот в ответ
  пришлёт фото + название фильма.

## Команды разработчика

Доступны только пользователям, чей Telegram ID указан в `ADMIN_IDS`.

**Коды:**
- `/addcode` — запускает пошаговый мастер (код → название → фото).
- `/addcode 001 Форсаж 10` — то же самое одним шагом, если отправить как
  **подпись к фото** (сначала выбираете фото, в подписи пишете команду).
- `/delcode 001` — удалить код.
- `/stats` — статистика: пользователи, количество кодов, успешные/неудачные
  поиски, топ-5 популярных кодов.
- `/cancel` — отменить мастер добавления кода, если начали и передумали.

**Каналы (обязательная подписка):**
- `/addch @channel_username` — добавить канал. **Бота нужно предварительно
  добавить в канал администратором**, иначе проверка подписки не будет
  работать.
- `/delch @channel_username` — удалить канал из списка.
- `/ch` — показать список обязательных каналов.

> ⚠️ Ограничение: кнопка-ссылка на канал строится по его публичному
> username. Приватные каналы без username можно добавить для проверки
> подписки, но кнопка будет вести на `t.me` без конкретного канала —
> в этом случае лучше присылать пользователям инвайт-ссылку отдельно
> или доработать код, добавив хранение произвольной ссылки для канала.

## Установка локально

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # и вписать туда свой токен и ID
python bot.py
```

## Переменные окружения

| Переменная  | Обязательна | Описание                                           |
|-------------|-------------|-----------------------------------------------------|
| `BOT_TOKEN` | да          | Токен от @BotFather                                  |
| `ADMIN_IDS` | да          | ID разработчиков через запятую (узнать свой ID можно у @userinfobot) |
| `DB_PATH`   | нет         | Путь к файлу SQLite (по умолчанию `bot.db`)          |

## Деплой на Railway

1. Загрузите проект в GitHub-репозиторий (или используйте Railway CLI /
   drag-and-drop загрузку папки).
2. В Railway создайте новый проект из этого репозитория — Procfile и
   `requirements.txt` будут определены автоматически (Nixpacks).
3. В **Variables** добавьте `BOT_TOKEN` и `ADMIN_IDS`.
4. **Важно про базу данных:** файловая система Railway для обычных сервисов
   эфемерна — при каждом новом деплое `bot.db` будет создан заново, и все
   добавленные коды/каналы потеряются. Чтобы этого избежать:
   - подключите **Railway Volume** к сервису (Settings → Volumes),
     примонтируйте, например, на `/data`;
   - задайте переменную `DB_PATH=/data/bot.db`.
5. Задеплойте. Бот запускается в режиме long polling — открытый порт не
   нужен, вебхук не требуется.

## Технологии

- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram-ботов
- `aiosqlite` — асинхронный доступ к SQLite
- FSM (Finite State Machine) aiogram — для пошагового добавления кода
